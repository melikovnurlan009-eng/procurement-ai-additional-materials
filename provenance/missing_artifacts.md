# Known Limitations

## 1. Procurement Pathway source-discovery curation

The discovery crawler for this source family is included at
`code/scrapers/procurement_doc_counter/` and can be rerun. The final curated manifest used in
this project, `corpus_manifests/procurement_pathway_urls.jsonl` (1,690 URLs), is a refined,
de-duplicated, topic-annotated version of that crawler's raw output; the code that performed
that refinement step is not available. The raw crawl can be reproduced; the exact final manifest
cannot be regenerated byte-for-byte from the raw crawl alone.

## 2. Historical corpus-build environment

No exact package-version snapshot was captured at the time the corpus was originally built.
`environment/environment_notes.md` documents a currently-verified-compatible environment
instead, not the historical one.

## 3. Embedding model revision

`BAAI/bge-m3` is used throughout, but no exact HuggingFace revision/commit was logged at ingest
time.

## 4. TEST-split independence

The frozen TEST split was constructed and executed by the same process, not by an independent
evaluator. This is a methodological property of the underlying research, disclosed in the
thesis report itself.

## 5. LLM-driven steps are not seeded

Corpus text-emission chunking, controller planning/observation, and judging all call an LLM with
no fixed temperature or seed (`prw/llm.py`). Re-running these produces architecturally comparable
but not byte-identical output. Deterministic steps (ingestion, graph construction, indexing,
statistics computation from already-saved data) are exactly reproducible.

## 6. Per-item cache directories excluded

Per-scenario checkpoint caches and per-candidate judge-request caches are not included; their
content is fully represented in the consolidated JSONL files that are included
(`runs.jsonl`, `judgments_raw.jsonl`, `qrels_silver.jsonl`).
